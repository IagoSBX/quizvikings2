## 📖 Sobre o projeto

O Quiz Vikings é uma aplicação web de perguntas e respostas pensada para estudo e revisão de conteúdo escolar. O jogador escolhe seu nome, a matéria e o nível de dificuldade, responde às perguntas do banco de dados e entra para o ranking ao final da partida.

## ✨ Funcionalidades

- 🎓 Banco de questões em **Biologia, Matemática, Física, História, Português e Geografia**
- 🎚️ Três níveis de dificuldade: **Fácil, Médio e Difícil**
- 🏆 Ranking de jogadores por pontuação
- ⏳ Tela de carregamento animada e interface com efeitos visuais (glow/orbs)
- ⭐ Fluxo de desbloqueio premium (modal de confirmação de pagamento)
- 📱 Layout responsivo, pensado para uso em desktop e mobile

## 🧱 Tecnologias

- **HTML5**, **CSS3** e **JavaScript (Vanilla)**
- Dados das questões estruturados em arquivos próprios (`data/`)
- Deploy contínuo via **Vercel**

## 🗂️ Estrutura do projeto

```
├── index.html   # Estrutura das telas (home, quiz, ranking, sobre)
├── css/         # Estilos da aplicação
├── js/          # Lógica do quiz, ranking e navegação entre telas
└── data/        # Banco de questões por matéria/dificuldade
```

## 🚀 Como rodar localmente

```bash
git clone https://github.com/IagoSBX/quizvikings2.git
cd quizvikings2
```
